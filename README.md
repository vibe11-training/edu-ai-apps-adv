# 수업 준비 도우미

교사가 수업 정보를 바탕으로 퀴즈와 학습활동을 준비할 수 있도록 돕는 웹앱입니다.

## 주요 기능

- **퀴즈 생성기:** 과목, 학년, 주제, 목표, 문항 수와 난이도를 입력하여 객관식 문항과 정답·해설을 생성합니다.
- **학습활동 추천:** 수업 정보와 활동 시간, 학생 수, 모둠 인원 등을 입력하여 학습활동 3개를 추천받습니다.

각 결과는 전체 복사하거나 UTF-8 BOM CSV로 내려받을 수 있습니다. 생성 결과는 사용 전에 교사가 정확성과 수업 적합성을 확인해야 합니다.

두 기능에서 정보 관련 과목, 중1~고3 학년과 학습 주제를 목록에서 선택하고 학습 목표를 직접 입력합니다.

## 실행 방법

`--env-file-if-exists`를 지원하는 Node.js와 npm이 필요합니다.

1. 의존성을 설치합니다.

   ```sh
   npm install
   ```

2. 프로젝트 루트의 `.env.local`에 아래 환경변수를 설정합니다.

   - `AI_ENDPOINT`: AI API의 기본 URL
   - `AI_API_KEY`: AI API 인증 키
   - `AI_DEPLOYMENT`: 사용할 모델 배포 이름

   실제 키는 직접 설정하고 저장소에 올리지 마세요.

3. 서버를 실행합니다.

   ```sh
   npm start
   ```

4. 브라우저에서 `http://127.0.0.1:3000`을 엽니다.

Windows PowerShell에서 npm 실행이 제한되면 `npm.cmd install`, `npm.cmd start`를 사용할 수 있습니다.
